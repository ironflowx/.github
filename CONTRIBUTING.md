# Contributing

ironflowx repositories do not accept outside contributions. Pull requests can be opened only by
collaborators, and a pull request from a fork, or from anyone but a maintainer, fails the
required `maintainer-only` check and cannot be merged. This applies to changes written by hand
and to those written by AI agents or bots.

You are welcome to use the code under its license, and to fork it for your own use.

- To report a bug, describe it to the maintainers; do not send a fix.
- Security problems go through [SECURITY.md](SECURITY.md), not public issues.
